# Success Book Hub - Development Guidelines

## Architecture Overview
- **Frontend**: TanStack Start + React 19 + Tailwind CSS with rich Maroon, Cream, and Gold design system.
- **Backend**: Node.js & Express REST API (`http://localhost:5000`) with native SQLite (`node:sqlite`).
- **Data Persistence**: Native SQLite database at `Backend/data/successbookhub.db`.

## Key Commands
- Start Backend: `cd Backend && npm start`
- Start Frontend: `cd Frontend && npm run dev`
- Build Frontend: `cd Frontend && npm run build`
